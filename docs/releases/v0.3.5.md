轻阅 0.3.5 完善阅读状态、网页下载、搜索与手动备份恢复。版本号为 0.3.5，versionCode 为 19。

## 主要变化

- 快速切书、切章、取消旧请求时保留正确正文与字符锚点；退出、重开及新进程恢复保持阅读进度。
- 网页预览与输入 URL 保持一致，重复确认和追更不会重复创建任务或章节；后台暂停、取消、删除及有界重试语义一致。
- 自定义排版独立保存，经过预设切换和重启仍保留；改善大字号、短横屏、夜间工具和搜索页面的可读性。
- 搜索明确区分完整结果与仍可续查的结果；支持返回原结果列表及查找前的阅读位置。
- 新增手动备份恢复：校验归档、预览重复书籍、默认跳过已存在书籍，保留正文、进度和书签；可选择恢复设置，不备份密钥。
- 修复指定应用语言后文件选择器可能崩溃的问题。

## 数据兼容

Room schema 从 8 非破坏升级至 9，保留原有书籍、章节、进度和书签。备份格式为 archiveVersion 1；已验证 TXT、EPUB、WEB 三种书籍在全新安装中的恢复与再次打开。

正式 APK 由仓库既有发布签名配置生成；发布流程对同一 tag SHA 执行质量检查，并核验 APK 包名、版本和签名。

## 验证与已知限制

- 本地实现回归：115 项 JVM 测试、113 项完整 QA、2 项实际宏基准和 16 项性能比较器用例通过；Lint 0 错误、63 警告、1 提示。
- 本地设备为 Android 16 / API 36 模拟器；GitHub 发布质量检查使用 API 35 模拟器。没有把历史 CI 结果用于本次发布。
- **UI 性能比较尚未通过原 15% 门槛。** 同环境 ABBA 测量中，排版重排 p95 分别退化 18.47% 和 20.11%，缓存翻页和工具列表也有部分越线。已保留全部失败与分段诊断；需要受控参考设备继续定位，未降低门槛或将结果认定为纯噪声。
- 分页引擎的四项比较通过，但其范围是已准备文本的分页和缓存查询，不等于用户操作至正文首帧的耗时。
- 未完成实体参考设备性能验收和真人 TalkBack 语音巡览。
