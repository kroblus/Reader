# 手动备份与搜索契约

## 手动备份 archiveVersion 1

归档是ZIP，唯一元数据为UTF-8 `manifest.json`。版本独立于Room schema 9；版本1是首个归档版本，没有已发布的更早格式。未知版本拒绝恢复，不猜测字段含义。

归档保存书籍稳定ID、来源、格式、标题作者、原始添加/阅读时间、导入指纹、章节原ID/顺序/来源/UTF-16长度/相对文件路径/字节长度/SHA-256、原进度及书签ID和时间、ReaderPreferences及自定义快照。当前TXT/EPUB/网页阅读器都读取已转换章节TXT；EPUB原压缩包不是现有引擎阅读所需资源。导出逐字复制现存正文，不做规范化。

API Key、IV、Android Keystore、AI配置、日志、搜索索引和下载暂存目录不在此结构内。仍保持`allowBackup=false`。

限制：最多10,000本/50,000正文文件，manifest最多8MiB，单正文64MiB，归档解压总量1GiB。拒绝绝对路径、`..`、反斜杠、冒号、重复条目和未声明资源；校验checksum、字节数、UTF-16长度及引用。剩余空间必须容纳准备副本并保留16MiB余量，复制过程中继续检查。排版设置需有限且有界，范围宽于当前UI以兼容旧偏好。

恢复先暂存到cache目录并显示可恢复、重复、无效书籍。默认按bookId或非空导入指纹跳过重复，包括归档内部重复；不合并/覆盖当前进度。用户可显式选择恢复阅读/外观设置，默认保留本机设置。

准备内容写入独立`files/restored-books/<随机目录>`并fsync，所有书籍/章节/进度/书签在一个Room事务中提交。bookId保留；章节ID在空库保留，在本机冲突时建立显式映射；书签保留原ID/位置/时间，碰撞时确定性映射且拒绝二次冲突。路径全部重建，不导入旧绝对路径或整个数据库。

取消/失败前的书库不变，事务回滚后的准备目录仅在确认未被books引用时清理；进程中断后根据数据库引用清理本功能私有目录，已提交书籍保留。默认重复恢复幂等。设置属于独立DataStore提交，失败明确显示“书籍已恢复但设置保存失败”，不冒充全部成功。

## 搜索

`SearchPage(results, hasMore, cursor, complete)`替代UI使用的截断List。页大小默认100，扫描有界章节批次，空批但仍有章节时必须显示“尚未检索完毕”并提供续查。全量兼容API通过迭代所有页实现。

FTS候选按rowid分批提取并按chapterId去重；候选不能证明任意子串不存在，因此最终以原文精确匹配扫描兜底，保持章节顺序。跨索引块、中文及英文子串都遵循原有不区分英文大小写且不重叠匹配语义。摘要裁剪不改变原文UTF-16偏移。

游标绑定bookId、查询词、章节身份/顺序/长度/路径/文件元数据版本；查询、书籍或内容变化拒绝旧游标。ViewModel集中请求代次保护结果/错误/loading，续页失败保留已加载结果。

只把查询、bookId、查找前chapterId/UTF-16偏移和可见列表索引/像素偏移写入SavedStateHandle，重建时按需重取到原列表位置。返回搜索结果保留上下文；回到查找前校验同书同章后恢复，仍走正常阅读保存。退出至书架结束旧原锚点上下文。
