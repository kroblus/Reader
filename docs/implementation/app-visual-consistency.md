# 首页封面与应用风格统一

日期：2026-11-14，随 0.3.6 发布。按用户在手机测试后的反馈，稍微缩小首页书籍图标，并以阅读“排版”面板的轻盈样式统一应用。

## 实现

- 最近阅读封面由 64×88dp 调整为 56×78dp；书架网格封面保留原比例、宽高缩小一成。卡片点击区域和 48dp 操作按钮热区保持不变。
- 空书架图标同步略微缩小。首页使用与其他页面一致的纯净底色，移除仅书架存在的背景装饰圆。
- 书架、应用设置、AI 设置、备份、导入、下载和搜索共用浅色卡片与 24dp 分组圆角，交互区域使用 16dp 圆角。应用设置用分组卡片替代逐行色块，图标底座与强调色统一。
- 四种应用配色保留，容器颜色先与底色合成，避免透明颜色在不同页面叠出不同深浅。正文纸色、夜间模式、个人字体和阅读排版继续使用用户选择。
- 界面跟随系统字体；语义、点击范围、导航与业务逻辑不变。已有主题测试覆盖普通文字、主按钮、卡片、选中项和错误提示的 4.5:1 对比度。
