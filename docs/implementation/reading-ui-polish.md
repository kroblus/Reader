# 阅读间距与设置页调整

2026-11-14；基于 v0.3.5（`207a07f6da19`）的未发布体验版。

## 行为

- 正文顶部只为常驻页眉预留空间：普通字号的保底距离从 52dp 减为 28dp，大字体按实际文字尺寸增加；仍尊重用户设置的较大顶部留白。临时工具栏显隐不触发重新分页。
- 章节标题后的额外间距从 30dp 减为 16dp。
- 快捷设置首先展示舒适、紧凑、沉浸三个预设，带选中状态和无障碍语义。已保存的自定义排版可在详细设置中通过“用我的排版”恢复。
- 详细设置按排版、翻页方式、阅读习惯分组；加入试读预览，行距与留白默认折叠，减少硬边框和技术单位。保留原有设置能力与拖动预览、结束后保存的行为。
